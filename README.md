# facturas-e-ingresos

Junta el extracto del banco y las facturas del trimestre en un único PDF:
portada, tabla de ingresos, una portadilla y las facturas detrás.

Todo pasa en el navegador. Los archivos no se suben a ningún sitio.

**Web:** https://antonioo420.github.io/facturas-e-ingresos/

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/index.html, autocontenido
```
