# facturas-e-ingresos

Webapp simple que junta el extracto del banco y las facturas del trimestre en un único PDF:
portada, tabla de ingresos y las facturas.

Todo se ejecuta en el navegador. Los archivos no se suben a ningún sitio.

**Web:** https://antonioo420.github.io/facturas-e-ingresos/

Para ejecutarlo en local:
```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/index.html, autocontenido
```
